Explain — Binary Addition Rules

The Four Rules of Binary Addition

0 + 0 = 0

No carry

0 + 1 = 1

No carry

1 + 1 = 10

Write 0, carry 1 ⬆️

1 + 1 + 1 = 11

Write 1, carry 1 ⬆️

Key Insight: The only difference from decimal addition is that 1 + 1 = 10 (not 2). Everything else follows the same column-by-column pattern with carries — just like the decimal addition you've done since primary school.

Explain — Overflow

What is Overflow?

Definition

Overflow occurs when the result of a binary addition is too large to be stored in the available number of bits.

Why Does It Matter?

Computers use a fixed number of bits (e.g., 8 bits, 16 bits, 32 bits) to store numbers. If the sum needs more bits than available, the extra bit is lost — causing an incorrect result.

Explain — Detecting Overflow

How to Detect Overflow

No Overflow

There is a carry into the MSB column AND a carry out of it — they match.

Overflow!

There is a carry OUT of the MSB but NO carry IN — or vice versa. They don't match.

Simple Check

If the carry OUT of the leftmost column = 1, check if it fits in your bit width.

IGCSE Exam Tip

For IGCSE exams, the simplest way to identify overflow:

✅ NO OVERFLOW

The result fits within the given number of bits. The leftmost carry is 0.

❌ OVERFLOW OCCURS

There is a carry beyond the most significant bit (MSB). The result needs more bits.

Key phrase to use in exams: "An overflow error has occurred because the result of the addition requires more bits than are available."

Overflow?

Q9. Explain in your own words

A student adds two 8-bit numbers and gets 00000011. The teacher says "overflow occurred." Explain why the student's answer is wrong and what the correct approach would be.

Explain

The result 00000011 (= 3) is likely wrong because overflow occurred — the true sum exceeded 255 and the 9th carry bit was lost. The correct approach is to use more bits (e.g., 16-bit) to store the result, or the programmer should check for overflow before the operation.

Q6. Define overflow error [3 marks]

• An overflow error occurs when the result of a calculation is too large to be stored in the allocated number of bits [1]

• This happens when a carry is generated beyond the most significant bit [1]

• The extra bit is lost, resulting in an incorrect answer [1]

Accept: "when the result exceeds the maximum value that can be represented" etc.

Q7. 200 + 100 in 8-bit [4 marks]

• 200 = 11001000, 100 = 01100100 [1]

• Sum = 100101100 which is 9 bits [1]

• 8-bit storage can only hold 8 bits, so the leftmost bit (carry) is lost [1]

• Stored result = 00101100 (= 44), which is incorrect — overflow error [1]

Q8. Two methods to avoid overflow [2 marks]

Any two of:

• Use a larger number of bits (e.g., 16-bit or 32-bit instead of 8-bit) [1]

• Check if overflow will occur before performing the addition [1]

• Use a programming language with arbitrary-precision integers [1]

• Use error handling / exception handling to catch overflow [1]
