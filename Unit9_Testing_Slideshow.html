Lesson Objectives

Syllabus A04 · A05

By the end of these two sessions, students will be able to:

  1. Define testing within the design process and explain why testing is essential before manufacture.
  2. Identify and describe six types of testing: functional, user (ergonomic), performance, aesthetic, safety and environmental.
  3. Explain the importance of testing a prototype against the design specification.
  4. Distinguish between destructive and non-destructive testing of materials and components.
  5. Construct a structured test plan that records what is tested, the method, expected result and actual result.
  6. Describe the iterative design process and explain how testing drives refinement of a 3D-designed product.
Exam alignment: Cambridge IGCSE D&T 0445/0979 Paper 1 assesses testing through short-answer and design-response questions. The coursework project (Component 2 or 4) requires a written testing report against the specification.

5,127 Prototypes

Engage · 5 min

Between 1979 and 1984, British inventor James Dyson built 5,127 prototypes of his bagless vacuum cleaner before he had a working product.

Each prototype failed in a different way — dust escaped, suction dropped, parts broke, the cyclone clogged. Each failure taught him something specific about what to change in the next version.

The final Dyson Dual Cyclone became one of the best-selling vacuum cleaners in the world and made Dyson one of the UK's richest engineers.

Discussion prompt: What if Dyson had stopped at prototype #100? Why is testing each prototype against the specification more useful than just "trying it and seeing if it works"?
Prototype testing — the heart of iterative design

Why Does Testing Matter?

Explore · 5 min

Discuss in pairs — 2 minutes per question, then share with the class.

  1. Think of a product you own that broke or didn't work as advertised. What should the manufacturer have tested better before selling it?
  2. A new 3D-printed phone stand looks good but slips on a smooth desk. Which kind of testing would have caught this?
  3. Imagine you designed a children's toy. What types of testing are essential before it can be sold?
  4. If a designer skips testing and ships the product, who pays the cost — the designer, the manufacturer, the user, or society?
Key idea: Testing is how we move from “I think it works” to “I have evidence it works”. It protects the user, the manufacturer and the designer's reputation.

What Is Testing in Design?

Explain

Testing is the systematic process of checking that a prototype (or product) meets its design specification and works as intended for its user.

Why we test

  • To check the prototype meets the design specification
  • To find faults and weaknesses before manufacture
  • To confirm the product is safe for the intended user
  • To gather evidence for the design portfolio

When we test

  • After the first prototype is made
  • After each iteration or refinement
  • Before mass production begins
  • As a final quality check on the manufactured product
Cambridge exam tip: Testing is part of the iterative design cycle: Design → Make → Test → Evaluate → Refine. Each cycle should produce evidence (photos, measurements, user feedback) that justifies the next change.

Six Types of Testing

Explain
Type What it checks Example test method
Functional Does the product do what it was designed to do? Operate the product as the user would; check each function listed in the specification
User (ergonomic) Can the intended user operate it comfortably and safely? User trials, observation, questionnaires, anthropometric data
Performance Does it meet measurable performance targets (load, speed, durability)? Stress tests, load tests, drop tests, cycle tests
Aesthetic Does the appearance match the design intent and appeal to the target market? Focus groups, preference surveys, comparison with moodboard
Safety Does it comply with safety standards and pose no risk to the user? Sharp-edge test, small-parts test, toxicity test, electrical safety test
Environmental Will it survive the conditions of use (temperature, moisture, UV, drop)? Climate chamber, salt spray, UV exposure, immersion test
Memory aid: “FU PASE” — Functional, User, Performance, Aesthetic, Safety, Environmental.

09 / 33

Functional Testing

Explain

Functional testing checks whether the prototype performs each function listed in the design specification.

How to do it

  1. List every function from your specification (e.g., “holds phone in portrait and landscape”).
  2. Operate the prototype exactly as a user would.
  3. Record whether each function works — with photos or video evidence.
  4. Note any function that fails, partially works, or requires too much force / dexterity.

Example: 3D-printed phone stand

  • Function 1 — holds phone upright: pass
  • Function 2 — stable on smooth surface: fail (slides)
  • Function 3 — allows charging cable to connect: pass
Evidence tip: Cambridge coursework expects photographs of the functional test in progress — not just a written description.
Functional Testing
10 / 33

User (Ergonomic) Testing

Explain

User testing checks whether the intended user can operate the product comfortably, safely and efficiently.

Common methods

  • User trials: watch real users complete a task; time them and observe errors
  • Questionnaires / surveys: ask users to rate ease of use, comfort, appearance
  • Focus groups: small group discussion led by the designer
  • Anthropometric checks: compare product dimensions with body-size data for the target user (e.g., 5th–95th percentile hand size)

Example: 3D-printed door handle

A handle designed for “adult hand, 50th percentile” should be tested with both small (5th percentile) and large (95th percentile) hands — not just the designer's own hand.

Cambridge exam tip: “Designer bias” is a common weakness — testing only with yourself is not user testing. Always test with the intended user group.
User Testing
11 / 33

Performance Testing

Explain

Performance testing measures whether the product meets specific quantitative targets (load, speed, durability, accuracy).

Common performance tests

  • Load / stress test: apply a known force and check it does not break (e.g., bookshelf holds 20 kg)
  • Drop test: drop from a specified height and check for damage
  • Cycle / fatigue test: open and close a hinge 10,000 times; check it still works
  • Accuracy test: measure dimensions against the specification (e.g., ± 0.5 mm)

Example: 3D-printed bracket

Specification: “support a 5 kg load without permanent deformation.” Hang a 5 kg weight on the bracket for 1 minute — measure deflection with a ruler before, during and after.

Why measure with numbers? A statement like “it broke” is opinion. A statement like “it failed at 3.2 kg, below the 5 kg target” is evidence. Cambridge rewards evidence.
Performance Testing
12 / 33

Aesthetic & Safety Testing

Explain

Aesthetic testing

Does the appearance match the design intent and appeal to the target market?

  • Compare the prototype with the original moodboard
  • Show the prototype to a focus group from the target market
  • Ask users to rate colour, shape, texture, finish (1–5 scale)
  • Use A/B preference tests between two design options

Aesthetic is subjective — so test with multiple users, not just one.

Safety testing

Does the product pose any risk to the user or to children?

  • Sharp-edge test: run a cotton wool swab along edges — any snagging is a fail
  • Small-parts test: check no part fits inside a “small parts cylinder” (for toys)
  • Toxicity test: confirm materials are food-safe / non-toxic
  • Stability test: does it tip over under normal use?
  • BS / CE / EN standards compliance check
Safety is non-negotiable: A product that fails the safety test cannot be sold — no matter how well it scores on the other five tests.
Aesthetic & Safety Testing
13 / 33

Environmental Testing

Explain

Environmental testing checks that the product will survive the conditions it will meet in real use — temperature, moisture, UV light, impact, vibration.

Common environmental tests

  • Temperature: hot / cold chamber (e.g., -20°C to +60°C)
  • Moisture: water spray, immersion or humidity chamber
  • UV exposure: sunlight simulator to check colour fading
  • Salt spray: corrosion resistance for metals
  • Vibration: simulated transport conditions

Example: outdoor 3D-printed plant pot

The pot will sit outdoors. Tests should include:

  • UV exposure test (does PLA biodegrade / fade?)
  • Water immersion (does it absorb water and weaken?)
  • Drop test onto concrete from 1 m

Material choice (e.g., PETG, ASA, ABS) is driven by environmental testing.

Design tip: Always test in the conditions of use, not in the design room. A 3D-printed part that feels strong indoors may become brittle after 6 months of sunlight.
Environmental Testing

Testing Against the Specification

Explain · Cambridge coursework essential

Every test must trace back to a specific point in your design specification. If a test does not match a specification point, it is either an unnecessary test or your specification is incomplete.

When Testing Was Skipped

Engage · 5 min

Three famous product failures that better testing could have prevented:

Samsung Galaxy Note 7 (2016)

Batteries caught fire on a global scale. The recall cost Samsung an estimated US$5.3 billion. The cause: a battery design that passed manufacturing tests but failed real-world thermal testing.

Segway PT (2001)

Hyped as the future of transport, but it failed user testing with the actual target market (commuters in cities) — too heavy to carry, too fast for pavements, too slow for roads.

Discussion prompt: For each failure, which type of testing was skipped or done poorly? (Performance / User / Environmental / Safety?)

What Is a Test Plan?

Explain

A test plan is a structured document that records what is being tested, how it will be tested, what the expected result is, and what the actual result was.

Why use a test plan?

  • Forces the designer to think before testing — not test on the spot
  • Provides evidence for the design portfolio and Cambridge coursework
  • Allows tests to be repeated by another person and checked for reliability
  • Makes it obvious which tests have not been done yet

Standard structure

Test IDSpecification pointTest typeMethodExpectedActual
T1     
Cambridge coursework tip: The Cambridge portfolio guide explicitly asks for a “testing report” with this structure. Marks are lost when students test informally and do not record the actual result.

Destructive vs Non-Destructive Testing

Explain
Non-destructive testing (NDT)Destructive testing
Definition The product / sample is not damaged by the test and can still be used The product / sample is damaged or destroyed by the test
When used Functional, user, aesthetic, dimensional, visual inspection Tensile, hardness, fatigue, stress-to-failure tests
Examples Visual inspection, weighing, measuring, drop test (if it survives), user trial Pull test to break, fatigue to failure, crush test, chemical analysis
Cost Low — same prototype can be reused High — each test consumes a sample
Use in school Most school testing is NDT (we have only one prototype!) Used only for material samples, not the final prototype
Cambridge exam tip: Be ready to classify a test as destructive or non-destructive. A drop test that the product survives is non-destructive; a drop test that breaks it is destructive — the test itself is the same, the outcome differs.

Materials Testing

Explain

Before a material is chosen for a product, samples are tested to confirm the material has the required properties. Common materials tests:

Common materials tests

  • Tensile test: how much force a sample takes before it stretches or snaps
  • Hardness test: how well a material resists scratching or indentation
  • Impact test: how much energy a sample absorbs when struck (e.g., Izod, Charpy)
  • Fatigue test: repeated loading cycles until failure
  • Flexure test: how much a sample bends before breaking
Tensile testing machine — measures load vs extension
For 3D-printed parts: material tests are especially important because printing orientation, layer adhesion and infill density all affect the final strength — the bulk material data sheet does not tell the full story.
Materials Testing

Iterative Design & Testing

Explain

Iterative design is a cyclic process of designing, making, testing and refining. Each cycle uses the test results to improve the next prototype.

Design  →  Make  →  Test  →  Evaluate  →  Refine  →  (repeat)

Why iterate?

  • First prototypes almost never work fully
  • Test results reveal problems the designer did not foresee
  • Users behave differently from designers
  • Each cycle is faster and cheaper than a single “perfect” attempt

3D printing and iteration

3D printing is ideal for iterative design because:

  • Each prototype can be made in hours, not weeks
  • Changing the CAD model and reprinting is cheap
  • Multiple variations (A/B) can be tested side by side
  • Failed prints are still evidence for the portfolio
Dyson's 5,127 prototypes were an iterative design process — each failure taught him what to change next. Iteration is not “starting again”; it is building on what you learned.
